# 本地面板界面说明

入口 `web/index.html`，资源 `web/app.js` 和 `web/style.css`。静态服务需把页面映射到 `/`，脚本映射到 `/app.js`，样式映射到 `/style.css`。页面仅向同源 `/api/*` 发请求，不使用外部资产。

启动地址的 `#token=...` 在脚本加载时转入 `sessionStorage`，随后清除 URL fragment。每个请求带 `X-Verge-Token`。会话结束后浏览器关闭会清除令牌。任何响应的 `error` 会显示在页面；所有 API 响应都按 `{ok: true, data}` 或 `{ok: false, error}` 解析。

“网站规则”中的新增、批量新增、停用、恢复和删除写入管理配置。“预览并应用”跳到“变更与备份”，从 `GET /api/plan` 展示即将应用的规则和文件，再通过 `deploy` 执行。操作结果保留后端返回的状态和 JSON 明细；只有明确的 `verified` 或 `active` 状态显示为“已验证生效”。`awaiting_client`、`partial` 和 `error` 各自显示不同状态。`verify` 用来重新检查客户端。

场景切换先调用只读 `GET /api/scene?name=...`，确认后才提交 `scene-use`。导入和旧手工规则接管也先发送预览请求，再提供确认提交按钮。导入选择本机 JSON 文件；前端从主映射和各场景的基础订阅、规则及节点偏好中提取外部订阅名称，用户可绑定到本机订阅。最终绑定和原始解析文档由后端检验。导出使用浏览器 Blob 下载接口返回的数据。

前端每 25 秒轻量读取一次快照。编辑表单或订阅别名时仍读取状态与提醒，但暂不重建界面，避免打断输入。操作请求进行中跳过本轮读取。所有写入动作完成后重新读取快照。节点详情和应用计划按入口单独读取。

浏览器通知按钮请求浏览器权限；快照中新增或级别升级的提醒会触发一条汇总通知。面板用 `sessionStorage` 记录已见提醒，解决后清除记录，避免重复通知。关闭面板后停止浏览器提醒。“发送提醒”调用后端 `notify`。本地面板自身不记录或显示订阅 URL、密钥。
